## อัปเกรดความปลอดภัย (ทำตามลำดับ)

1. Deploy หน้าเว็บเวอร์ชันนี้ขึ้น GitHub Pages ก่อน — ใช้ได้ทั้งกับฐานข้อมูลเดิมและฐานข้อมูลที่อัปเกรดแล้ว
2. Supabase → SQL Editor → รัน `sql/01-security-staff-auth.sql` ทั้งไฟล์
3. ล็อกอินแอดมิน → ตั้งค่า → 🔧 ตรวจสอบระบบ ต้องขึ้น “โหมดปลอดภัย”
4. เปลี่ยนรหัสแอดมินด้วยปุ่ม 🔑 มุมขวาบน
5. ให้ทุกเครื่องรีเฟรชแอปหนึ่งครั้ง แล้วรัน `sql/02-lock-business-tables.sql`

หลังรันไฟล์ 01: รหัสผ่านทุกบัญชีถูกเข้ารหัส (bcrypt) ใช้รหัสเดิมเข้าได้ตามปกติ

## ระบบบัญชี (แท็บ 💰 บัญชี — แอดมินเท่านั้น)

- ต้นทุนรับซื้อ = ยอดบิล (`orders.grand_total`) ที่ไม่ถูกยกเลิก นับตามวันที่บิล — นับ 1 ครั้งต่อบิล
- การจ่ายเงิน (ใบเสร็จ/วันที่ชำระ) ใช้แสดงยอดจ่ายแล้ว/ค้างจ่าย/กระแสเงินสด — ไม่บวกซ้ำกับต้นทุน
- ค่าใช้จ่ายเพิ่มเติม = ตาราง `expenses` (ลบแบบซ่อน กู้คืนได้ มีประวัติทุกการแก้ไขใน `acct_audit`)
- รายรับ = ตาราง `rubber_sales` — ถ้าไม่มีข้อมูลการขาย ระบบแสดง "ไม่มีข้อมูล" แทนการเดากำไร
- ตัวเลขสรุปคำนวณในฐานข้อมูล (`acct_report`) และตรวจความถูกต้องของบิล/ใบเสร็จก่อนแสดงผล

## บัญชีพนักงานจ่ายเงิน (แท็บ 💵)

- พนักงานจ่ายเงินเห็นเฉพาะบัญชีของตัวเอง (บังคับในฐานข้อมูล) / แอดมินเลือกดูได้ทุกคน
- รายรับ = เงินทดรองที่แอดมินบันทึกให้ · รายจ่าย = ใบเสร็จที่พนักงานคนนั้นออก (จ่ายค่ายาง) + ค่าใช้จ่ายที่จ่ายเอง + ส่งเงินคืน
- ผู้ออกใบเสร็จถูกกำหนดจาก token ฝั่งเซิร์ฟเวอร์ · เงินคงเหลือแสดงเมื่อมีการบันทึกเงินทดรองแล้วเท่านั้น
